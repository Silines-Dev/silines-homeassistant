# Интеграция Silines для Home Assistant

[English Setup Guide](./README.md) | **Русское руководство по настройке**

Полнофункциональная кастомная интеграция для контроллеров **Silines** (например, серии BOREAS) в Home Assistant. Интеграция работает полностью локально через асинхронный опрос по HTTP.

---

## 📦 Установка

### Способ 1: Через HACS (Рекомендуется)

1. Откройте **HACS** на боковой панели Home Assistant.
2. Нажмите на **три точки** в правом верхнем углу и выберите **Пользовательские репозитории** (Custom repositories).
3. Вставьте URL-адрес этого репозитория в поле **Репозиторий**.
4. Выберите категорию **Интеграция** (Integration) и нажмите **Добавить**.
5. Найдите **Silines** в списке интеграций и нажмите **Скачать** (Download).
6. **Перезапустите** сервер Home Assistant.

### Способ 2: Вручную

1. Склонируйте или скачайте этот репозиторий.
2. Скопируйте папку `custom_components/silines` в директорию кастомных компонентов вашего Home Assistant (например, `/config/custom_components/silines`).
3. **Перезапустите** сервер Home Assistant.

---

## ⚙️ Настройка

1. В интерфейсе Home Assistant перейдите в **Настройки** ➡️ **Устройства и службы**.
2. Нажмите кнопку **Добавить интеграцию** в правом нижнем углу.
3. Найдите в поиске **Silines** и выберите его.
4. Заполните форму сетевых параметров и данных авторизации:
   * **IP-адрес устройства:** Локальный IP-адрес контроллера Silines.
   * **Порт:** HTTP-порт веб-интерфейса (По умолчанию `80`).
   * **Логин / Пароль:** Данные учетной записи для доступа к веб-панели прибора.
   * **Интервал опроса:** Частота обновления данных в секундах (Минимум `5` сек).
   * **Таймаут ответа API:** Максимальное время ожидания ответа от контроллера.
5. Нажмите **Подтвердить**.
